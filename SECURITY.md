# Política de seguridad · Security policy

## Español

**Reporta las vulnerabilidades en privado** con el reporte privado de vulnerabilidades de GitHub: pestaña **Security** → **Report a vulnerability** de este repositorio. No abras un issue público, y no incluyas datos reales de préstamos ni datos personales en el reporte; describe el problema con datos sintéticos.

- **Alcance:** el código de este repositorio y el sitio publicado desde él. CuotasCasa no tiene backend: los datos viven en el navegador y, opcionalmente, en una copia cifrada en el Google Drive del usuario.
- **Respuesta:** es un proyecto personal; el objetivo es confirmar la recepción en 7 días y acordar contigo la fecha de divulgación.
- **Versiones con soporte:** solo la rama `main` y la última versión publicada.

## English

**Report vulnerabilities privately** through GitHub private vulnerability reporting: this repository's **Security** tab → **Report a vulnerability**. Do not open a public issue, and do not include real loan data or personal data in the report; describe the problem with synthetic data.

- **Scope:** the code in this repository and the site deployed from it. CuotasCasa has no backend: data lives in the browser and, optionally, in an encrypted copy in the user's Google Drive.
- **Response:** this is a personal project; the goal is to acknowledge reports within 7 days and agree on a disclosure date with you.
- **Supported versions:** only the `main` branch and the latest release.
