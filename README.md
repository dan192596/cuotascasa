# CuotasCasa

> **En construcción · Work in progress.** Todavía no hay una versión usable. · There is no usable release yet.

## Español

CuotasCasa es una app web _local-first_ para modelar las cuotas de préstamos de vivienda en Guatemala (fórmula FHA), proyectar abonos a capital y comparar lo proyectado con lo real. No se conecta a bancos ni mueve dinero: tus datos viven en tu navegador y, si lo eliges, en una copia cifrada en tu Google Drive.

**Solo datos sintéticos.** Este repositorio es público. Ningún monto, tasa, fecha, número de préstamo, documento ni dato personal real entra aquí: todos los ejemplos y fixtures son sintéticos y llevan `synthetic: true`.

Licencia: [MIT](LICENSE). Para reportar una vulnerabilidad, lee [SECURITY.md](SECURITY.md).

## English

CuotasCasa is a _local-first_ web app to model home-loan installments in Guatemala (FHA formula), project principal prepayments and compare the projection with what actually happened. It never connects to banks or moves money: your data lives in your browser and, if you choose, in an encrypted copy in your Google Drive.

**Synthetic data only.** This repository is public. No real amount, rate, date, loan number, document or personal data goes in here: every example and fixture is synthetic and carries `synthetic: true`.
