cc-export-menu implementing its frozen API: writers loaded by dynamic import on click, download via Blob plus an anchor, filenames cuotascasa-<tabla|comparacion>-<vista>-YYYY-MM-DD.<ext> (no personal data), progress state and completion announcement. Before the first download of each session a Spanish warning says 'el Excel, CSV o PDF no va cifrado y contiene datos financieros'.
