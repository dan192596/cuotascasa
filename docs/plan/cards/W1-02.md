## Entregables
Stdlib-only (decimal, json, random, hashlib) implementation of the core algorithm with the FORMAT.md decimal context ([ALG.CONV]), including [ALG.ZERO], the [ALG.DATES] consistency check (InvalidInputError) and [ALG.LAST] with financialCharge for both stop tests. CLI entry point `python -m cuotascasa_oracle`, matching the W0-01 root scripts (oracle:gen, oracle:diff) and the W0-04 pyproject: `python -m cuotascasa_oracle generate --profile P --seed S --out DIR` writes DIR/<fixture-id>.json (naming rule from FORMAT.md) and merges the profile entry (seed, count, generatorVersion) into DIR/manifest.json, leaving other entries untouched; `python -m cuotascasa_oracle regenerate --manifest DIR/manifest.json` re-runs generate for every profile listed there with its recorded seed, for oracle-diff (a profile whose manifest generatorVersion is behind GENERATOR_VERSION is reported as 'regeneration pending: <profile>' and left untouched, per W2-01; profiles absent from the manifest are ignored). Profile 'core' emits the composition fixed in FORMAT.md (exact count, no events); each loan's RNG is seeded from (profile, seed, index) so adding a profile never changes existing output; files use sorted keys and stable formatting, carry synthetic: true, the feature tag core and trait tags (roundingProfile:FHA_GT_V1|SIMPLE, paymentDay:numeric|EOM, currency:GTQ|USD, lastRow, where lastRow = the last row's total differs from level + fixed charges or the loan pays off before termMonths). A GENERATOR_VERSION constant is written into every fixture. `compare` reads a-terms.json and a-expected.csv in the private schema of FORMAT.md from any path, rejects a different CSV header and prints exactly three labeled lines: 'allRowsMatched: yes|no', 'mismatchedRows: <int>', 'maxAbsDiff: <d.dd>'; it never prints the total row count (not even in the terminal). `--log-line` takes `--sha <git sha>` and `--label <a|b…>` and prints 'AAAA-MM-DD · oráculo <sha> · préstamo <label> · todas las filas coinciden: sí/no · filas con diferencia <k> · dif. máx. <d>'. pytest suite plus ruff. A test-only profile may be registered inside tests/ (never in cuotascasa_oracle/) to prove profile isolation.
