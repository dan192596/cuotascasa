## Entregables
Completes docs/algorithm.md so two isolated lineages (TS engine and Python oracle) can implement it without guessing. Every rule gets a stable section id (e.g. [ALG.RATE.KEEP_INSTALLMENT]). Adds: (1) the decimal context [ALG.CONV] (precision 34, ROUND_HALF_EVEN, cents only via HALF_UP_2), r = (i+f)/12 unrounded, fixed operation order; (2) every event semantic, including the derived term [ALG.TERM], the anchor re-base [ALG.ANCHOR] and the total order [ALG.EVENTS.ORDER]; (3) one synthetic worked example (3-6 rows plus the last row) for every item of [ALG.PENDING] in docs/algorithm.md, besides the core example [ALG.EXAMPLE]; examples with events go in separate JSON files from event-free ones; (4) closed definitions: Real delta, interestSaved, monthsSaved, netSaving, endDate, totalPaid (incl. fixed charges and commissions), yearly subtotals (calendar year of dueDate, which columns are summed), goal-seek outcomes, numeric traffic-light thresholds and a closed enum of causes; (5) 'Hipotecario simple' template values. Machine-readable copies of every example go to docs/specs/algorithm-examples/*.json (synthetic: true, section id, decimal strings) with an INDEX.md checklist.
