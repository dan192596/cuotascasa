## Entregables
tools/hygiene/denylist.mjs reads $CUOTASCASA_DENYLIST or ~/.config/cuotascasa/denylist.txt (must resolve outside the repo), scans added staged lines with number normalization (commas, spaces, currency symbols) and case-insensitivity, and passes with a notice when the list is absent. noreply.mjs requires a git user.email ending in @users.noreply.github.com. synthetic-flag.mjs requires top-level synthetic: true in every JSON under fixture dirs (packages/schema/fixtures, tools/oracle/fixtures, docs/specs/algorithm-examples, e2e/fixtures); the same entrypoint runs `git ls-files --others --ignored --exclude-standard` over those dirs and fails if any fixture file would be ignored. renovate.json: weekly schedule, minimumReleaseAge 7 days, Angular/Material grouped, exact pins, lockFileMaintenance, dashboard approval for majors, pip requirements in tools/oracle covered.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Vitest tests with temp git repos: a denylisted term in the staged diff fails, including '1,234,567.89' vs '1234567.89'; a list file inside the repo is refused; an absent list passes
- [ ] The noreply check fails for a non-noreply email and passes for a noreply one
- [ ] The synthetic-flag check fails for a fixture without synthetic: true
- [ ] Denylist output contains only file paths and line numbers, never list contents (test)
- [ ] renovate.json parses and contains the required keys incl. the pip manager (test)
- [ ] The fixture-ignore check fails in a temp repo when `git ls-files --others --ignored --exclude-standard` reports a file under a fixture dir (e.g. packages/schema/fixtures/x.csv) and passes on a clean tree
