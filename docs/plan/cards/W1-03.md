## Entregables
parseBackup(text|unknown) returns Result<{document, migratedFrom, preview}, BackupError>: JSON parse, format 'cuotascasa' check, version detection, pure migration chain to latest, zod validation with path-precise errors, active/tombstoned counts per entity; it strips the optional root synthetic flag. serializeBackup emits canonical, stably ordered output and never emits synthetic. Migration registry with per-version synthetic fixture folders (packages/schema/fixtures/backup/v1/backup-v1-<case>.json). fast-check arbitraries for every entity and whole documents, exported via @cuotascasa/schema/testing.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Malformed JSON, wrong format, a future version and an invalid money string each return a typed error; parseBackup never throws
- [ ] Per registered version the migration leaves a deep-frozen input unchanged and its output validates
- [ ] Property (1000 runs): serialize then parse deep-equals arbitrary documents
- [ ] Property: every arbitrary entity passes its zod schema
- [ ] Every file under packages/schema/fixtures/ is named backup-v1-<case>.json, has synthetic: true and parses to the latest version
- [ ] parseBackup strips the root synthetic flag and serializeBackup never emits it (test)

## Notas
With only v1 existing, the chain is proven with a test-only synthetic pre-v1 migration that is never registered in production.
