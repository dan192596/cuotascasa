## Entregables
Local harness serving candidate CSP headers. Part (a) lazily injects https://accounts.google.com/gsi/client, runs initTokenClient (scope drive.appdata, placeholder client id), opens the requestAccessToken popup, fetches Drive v3 (a 401 is fine) and calls revoke. Part (b) serves the W0 prerendered '/' and the '/app' CSR output. A Playwright runner (Chromium + WebKit) collects securitypolicyviolation events and console CSP errors across the matrix: Trusted Types enforced / report-only / off x Angular autoCsp / header hashes / post-build generated hashes. The evidence doc records violation counts per cell, the candidate header per route ('/', '/privacidad', 404, '/app/*') and the GIS loading options. The decision itself is Opus's (ADR-0021 in W2-02).
