## Entregables
ci.yml on PR and main: Node 24 with pnpm cache, frozen install, lint, typecheck, unit tests with coverage, build, owns-check, gitleaks over full history (fetch-depth 0), pnpm audit --prod --audit-level high, and validation of docs/specs/algorithm-examples. PR template (card id, owns, DoD checklist) and CODEOWNERS for shared files. tools/owns-check reads the card id from branch card/<id>-<slug> and the owns list from docs/plan/cards.json, diffs against the merge-base and fails on: any path outside owns; any path in docs/plan/frozen-files.json even inside an owned dir, unless the card id is in that entry's editableBy: [card ids] (planned: W2-01, W2-02, W3-01, W3-16, W3-17 and any registered Opus micro-card); a non-append change to an append-only file (tools/conformance/enforced-features.json may only gain tags); an unknown card id. Branches renovate/ and opus/ are exempt. tools/lint-fixtures holds one passing and one failing fixture per row of the ADR-0010 §5 matrix. tools/conformance/src is the Opus-written, frozen harness: it loads every fixture listed in tools/oracle/fixtures/manifest.json, validates it with the schema fixture schema, runs the public engine API and compares every row field and summary value to the cent. A fixture is enforced only when all its feature tags are in enforced-features.json (starts as []); the rest are reported as pending with a visible count and are not allowed to fail CI. Mismatch reports give fixture id, row, field, expected and actual. A harness test fails if any fixture id string appears under packages/domain/src/. It also ships private-compare, a CLI that reads a-terms.json and a-expected.csv in the private schema of tools/oracle/FORMAT.md from a path outside the repo, rejects a different CSV header and prints exactly three labeled lines 'allRowsMatched: yes|no', 'mismatchedRows: <int>', 'maxAbsDiff: <d.dd>', never the total row count (not even in the terminal); --log-line takes --sha <git sha> and --label <a|b…> and prints the validation-log line in the format fixed in tools/oracle/FORMAT.md, without the total row count or any term. Plan generator: adds a structured top-level section 'frozen_files': [{path, editableBy: [card ids]}] to docs/plan/plan.json, derived from wave0_contracts and shared_files_policy, and extends tools/plan/render_plan.py to also emit docs/plan/cards.json and docs/plan/frozen-files.json (the latter from 'frozen_files') next to the existing views; owns-check reads only those generated files. Owner steps recorded in the PR: branch protection (CI plus Opus review) and GitHub secret scanning plus push protection enabled before the first public push.
