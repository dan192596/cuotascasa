## Entregables
Playwright config with chromium and webkit projects whose webServer is the production build served by tools/edge/serve.mjs, so tests see the real _headers/_redirects. Exported helpers: expectNoExternalRequests, expectNoClientStorage (localStorage, sessionStorage, indexedDB.databases(), cookies, CacheStorage, SW registrations), expectNoA11yViolations (serious/critical), collectCspViolations, seedFromBackup(page, syntheticDoc) writing a v1 document into IndexedDB using the exported DEXIE_SCHEMA_V1. A Google mock routes accounts.google.com/gsi/client and the Drive v3 endpoints to the frozen gis-fake/drive-fake with an inspectable store.
