## Entregables
Loan cards showing the spec §9 derived values from LoanProjectionService (house meter = percentPaid, balance, nextInstallmentTotal, realEndDate plus activeScenarioEndDate when the active scenario has events, validation chip with 'Sin validar' for UNVALIDATED, status), per-currency totals over active loans, status filter activos/pagados/archivados, sync and backup status widget driven by SyncService status and BackupService.reminderDue, empty state with three actions (crear préstamo, restaurar respaldo, conectar Drive). The Safari banner lives only in the shell slot (W3-09); the dashboard does not host it (D26).
