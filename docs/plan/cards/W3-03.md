## Entregables
goalSeek(paths, request) supporting FINISH_BY(date) and MAX_INSTALLMENT(amount), returning the minimal prepayment at a given date as GoalSeekResult = ALREADY_MET | FOUND{amount, metrics, isPayoff} | INFEASIBLE{payoffAmount, reason} per [ALG.GOAL]. The search applies no commission; InfeasibleGoalError is thrown only for invalid inputs, never for an infeasible goal.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Property (>= 200 runs): the result satisfies the goal and result - 0.01 does not
- [ ] An already-satisfied goal returns ALREADY_MET; a goal unreachable even with payoff returns INFEASIBLE{payoffAmount, reason} without throwing; a FOUND amount that pays off the loan has isPayoff true; invalid inputs throw InfeasibleGoalError
- [ ] FINISH_BY uses REDUCE_TERM and MAX_INSTALLMENT uses REDUCE_INSTALLMENT, matching the goal-seek examples
- [ ] A bench test finishes a 360-month loan in < 200 ms in Node, with a CI tolerance factor
