## Entregables
The backup download in Ajustes follows the pattern export-support.ts already uses for Safari: the anchor is attached to the document, clicked, removed, and the object URL is revoked after the same lifetime (OBJECT_URL_LIFETIME_MS semantics, not immediately). Only after the click succeeds does the component call the W9-01 method that marks the backup; if building the file or the click throws, the backup is not marked and an assertive Spanish error says so. The success notice keeps its current wording. Same flow for the plain and the encrypted export.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Component spec: markExported is called once after the click and never when exportJson or the click throws; the object URL is not revoked synchronously (fake timers) and is revoked after the lifetime
- [ ] The anchor is in the document at click time and removed afterwards
- [ ] settings-backup.contract.spec.ts still passes unchanged; pnpm lint && pnpm typecheck && pnpm test pass
