## Entregables
SyncSession over the SyncProvider, LocalDataset and KeyStore ports: full pipeline in the order merge -> purgeTombstones over the merged dataset and local with the previous lastSyncAt -> save -> encrypt -> upload -> markSynced (ADR-0008 decision 4, ADR-0024), cuotascasa.prev.json handling, status machine, single-flight guard within a tab and across tabs (Web Locks API lock 'cuotascasa-sync').

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Tests use a fake provider built on packages/sync/src/testing, a fake LocalDataset and real crypto with test iterations
- [ ] With no remote file it uploads cuotascasa.json whose content is an envelope, never plaintext; with a remote it runs the full pipeline and saves the previous remote as cuotascasa.prev.json before overwrite
- [ ] NetworkError -> 'offline' with pendingChanges kept; AuthError -> 'needs-auth'; KeyMismatch or WrongPassphraseOrTamper -> 'needs-passphrase' with no upload and the local dataset untouched (spy)
- [ ] Call order is merge -> purgeTombstones (merged dataset and local, previous lastSyncAt) -> save -> encrypt -> upload -> markSynced; markSynced runs only after a successful upload (call-order spy)
- [ ] Concurrent sync() calls coalesce into one run, including across two tabs (fake LockManager)
- [ ] A tombstone purged in a run is not re-uploaded: the uploaded envelope decrypts to a dataset without it (test)
- [ ] The uploaded plaintext is serializeBackup(BackupDocument) whose data is the merged, purged dataset; a download goes through parseBackup: FUTURE_VERSION gives { state: 'error', code: 'UnsupportedVersion' }, and a remote that is not an envelope or any other parse failure gives { state: 'error', code: 'InvalidRemote' }; in both cases nothing is saved or uploaded (spy)
- [ ] sync() resolves with the outcome on every failure; with no remote file the remote side is the empty dataset, so the device settings record is never uploaded (test)
- [ ] If the remote file's version changed between download and upload, the run starts over from the download once and then uploads (fake provider)
