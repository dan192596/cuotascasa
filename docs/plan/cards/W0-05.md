## Entregables
Standalone, zoneless Angular 22.2 with OnPush as schematic default and es-GT registered. SSR outputMode 'static': '' and 'privacidad' prerendered, 'app/**' client-rendered through index.csr.html. app.routes.ts: '' -> public/landing, 'privacidad' -> public/privacy, 'app' -> loadChildren of the frozen app-area.routes.ts (lazy AppShell, route providers [provideAppData(), provideStorageHealth()], children loading every features/*/*.routes.ts), '**' -> public/not-found. Root app.config.ts: zoneless, router, hydration, LOCALE_ID, provideAppErrorHandling() (core/errors), provideAppTheme() (core/theme), provideAppPwa() (core/pwa, inert). data/api.ts, data/tokens.ts and data/provide-app-data.ts are frozen (data/api.ts and data/tokens.ts use only `import type` from packages): LoansStore (create without anchor, and createWithAnchor), LoanEventsStore, ReportedBalancesStore, PaymentsStore, ScenariosStore (activeScenarioId per loan), SettingsStore, LoanProjectionService (exposing the derived values defined in the spec §9 table: asOf, currentInstallment, balance, percentPaid, nextInstallmentTotal, realEndDate, activeScenarioEndDate, validation status including 'UNVALIDATED', suggestedPaid, and per-currency totals over active loans, plus cutoffK, the per-row paid flags and realDelta per anchor and per component from the domain paths), BackupService (incl. reminderDue signal), SyncService, StorageHealth (incl. requestPersist); provideAppData composes provideDataStores (data/providers/), the stores (data/stores/), provideEngineFacade (data/engine/), provideBackup (data/backup/) and provideSync (data/sync/). All app-level stubs are INERT: they return safe defaults (empty lists, status 'no-configurado', reminderDue false) and export a CC_STUB marker. Frozen page shells for split routes: loans (wizard/detail), scenarios (editor/compare), settings (backup/sync), real-data (timeline/forms). Every page root carries data-testid='page-<route-id>'. Stub components with frozen selectors, inputs and outputs, documented in component-contracts.md and guarded by a frozen *.contract.spec.ts each: cc-quick-simulator, cc-theme-toggle, cc-safari-banner, cc-update-prompt, cc-export-menu, cc-scenario-editor, cc-scenario-compare, cc-settings-backup, cc-settings-sync, cc-real-data-timeline, cc-event-form. styles/: styles.scss entry, tokens.css with placeholder values, Tailwind v4 entry, placeholder M3 theme; the frozen design contract lives outside styles/ in apps/web/src/design-contract/ (token-names.json plus tokens.contract.spec.ts asserting tokens.css defines exactly those custom properties in light and dark). privacy-requirements.md lists the required /privacidad section headings (Google consent-screen requirements). angular.json: define GOOGLE_CLIENT_ID as '' for development and test, stats JSON for production, budgets. environments/build-constants.ts reads the define. index.html links manifest.webmanifest; placeholder manifest in public/. Golden patterns in apps/web/src/app/_patterns/ (Signal Forms custom control, 2-step form with Spanish messages, zoneless component test, signal-store test) explained in angular-patterns.md. design-palette.md (base light/dark 'libreta bancaria' palette): present the proposal in docs/discovery/direccion-visual.md to the owner, record the approval date in docs/specs/design-palette.md, then freeze.
