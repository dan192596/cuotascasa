## Entregables
Provider that loads GIS lazily with the ADR-0021 method (Trusted Types policy if adopted), keeps the token in memory only, talks to the Drive v3 appDataFolder subset (list, download, multipart create/update, copy to prev) and revokes on disconnect. Tested only against the frozen drive-fake and gis-fake.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] The GIS script tag is injected only on connect() (absent before)
- [ ] No writes to localStorage, sessionStorage, IndexedDB or cookies; the token lives in memory only (storage spies)
- [ ] Every call in drive-api-subset.md is exercised against drive-fake; only hosts allowed by ADR-0021 are contacted
- [ ] An expired token is re-requested with prompt '' only inside a user-initiated sync; 401 -> AuthError; fetch failure -> NetworkError
- [ ] disconnect() calls google.accounts.oauth2.revoke and clears the token
