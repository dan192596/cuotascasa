## Entregables
EngineFacade.asOf becomes reactive: it derives from a «today» signal that re-reads Clock.today() when the page becomes visible again (visibilitychange/pageshow) and at the next local midnight while visible (one timer rescheduled each time, cleared when the injector is destroyed). Everything derived from asOf (current installment, balance, percent paid, next installment, cutoffK, totals, export generatedOn) follows. The value only changes when the date changes, so no recomputation happens on every visibility event. Fix the spec «derived values depend on asOf only» so it actually advances a mutable fake clock.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Spec with a mutable fake Clock: advancing one day and dispatching visibilitychange changes asOf and currentInstallment; dispatching it on the same day does not recompute (same signal value)
- [ ] Spec with fake timers: crossing local midnight while visible updates asOf; destroying the injector clears the timer and the listener
- [ ] loan-projection-service.spec.ts: the asOf test changes asOf and asserts the derived values change
- [ ] pnpm lint && pnpm typecheck && pnpm test pass
