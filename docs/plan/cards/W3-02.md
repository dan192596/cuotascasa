## Entregables
Arbitraries for LoanTerms and events plus the invariant suite with a fixed CI seed. Properties that fail because of an engine bug go to properties-pending.json and run as test.fails with a visible count; each entry cites the failing seed and is triaged by Opus.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Without anchors, sum(capital) + sum(principal prepaid) equals principal exactly (>= 200 runs)
- [ ] Without anchors, the balance is never negative and never increases period to period
- [ ] AdvanceInstallments(n) reduces the remaining term by exactly n; adding any valid prepayment never increases total interest
- [ ] A rate increase under KEEP_INSTALLMENT_ADJUST_TERM either throws NegativeAmortizationError or keeps the balance decreasing
- [ ] A quarantined property that starts passing fails the suite (forces its removal from properties-pending.json); the suite is green with the quarantine
