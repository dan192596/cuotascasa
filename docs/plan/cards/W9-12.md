## Entregables
The destructive confirm of cc-settings-device first states what would be lost: «N cambios sin sincronizar con Drive» (SyncService pendingChanges, when Drive is connected) and «N cambios desde el último respaldo» (BackupService.changesSinceBackup), with two ways out: «Sincronizar ahora» (calls sync(), shown only when Drive is connected and authorized) and «Ir a respaldos» (navigates to the backup section of Ajustes). When both counts are 0 the dialog says «Todo está respaldado o sincronizado». Typing BORRAR is still required in every case.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Component spec: the counts come from the services and update live; «Sincronizar ahora» calls sync() and is hidden without Drive; zero counts show the all-clear text
- [ ] e2e: with one unsynced synthetic change the dialog shows the count, and after «Sincronizar ahora» it shows 0 (Google fakes)
- [ ] The existing W7-04 specs and e2e still pass; pnpm lint && pnpm typecheck && pnpm test pass
