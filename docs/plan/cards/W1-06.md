## Entregables
mergeDatasets(local, remote) returns {merged, stats} with record-level last-writer-wins using the frozen RecordOrderKey (updatedAt, updatedByDevice; tombstone wins a full tie). purgeTombstones (signature frozen in ports.ts, rule in ADR-0008 decision 4) is a separate pure function: it removes tombstones with deletedAt < lastSyncAt − 90 days, lastSyncAt being the previous successful sync; a null lastSyncAt purges nothing; instants are compared in ms. Settings merge only synced fields; device-local fields are never merged. Record arbitraries local to this dir respect monotonic per-device stamping.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] fast-check (>= 500 runs each): mergeDatasets is commutative, idempotent and associative and never yields duplicate ids
- [ ] A newer tombstone beats an older edit; a newer edit beats an older tombstone; a full tie resolves to the tombstone
- [ ] Equal updatedAt resolves deterministically by updatedByDevice
- [ ] purgeTombstones boundary tests with lastSyncAt = the previous sync: deletedAt at lastSyncAt − 90 days and ± 1 ms (purged only when strictly earlier); lastSyncAt null purges nothing; all instants in ms
- [ ] Device-local settings fields never change through a merge; deep-frozen inputs stay unchanged; the module has no I/O

## Notas
Resurrection after purge and clock skew are documented residual risks (ADR-0024), not solved here.
