## Entregables
A functional canDeactivate guard in ui/feedback/unsaved-changes.ts asks components that implement a small HasUnsavedChanges interface, and uses cc-confirm-dialog («Tienes cambios sin guardar. ¿Salir de todos modos?» with «Seguir editando» as the default focus). A beforeunload listener is active only while a form is dirty. Wire it into the wizard route, the loan detail (edit form), «Datos reales» (event form) and «Proyecciones» (scenario editor). The wizard also gets a «Cancelar» that goes back to the dashboard through the same guard. A saved form or an untouched one never asks.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Guard spec: dirty → dialog; confirm leaves, cancel stays; clean → no dialog; beforeunload is registered only while dirty
- [ ] Component specs: each of the four forms reports dirty after an edit and clean after save or reset
- [ ] e2e (Chromium and WebKit): fill wizard steps 1-2, click «Ajustes» in the top bar, choose «Seguir editando» and find the data intact; axe without serious or critical issues on the dialog
- [ ] pnpm lint && pnpm typecheck && pnpm test pass
