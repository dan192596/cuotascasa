## Entregables
Generic CDK-based ledger table: ruled rows, monospaced tabular numbers, sticky header, current-row highlight, subtotal rows, roving-tabindex keyboard grid, per-row editable flag and an editable-cell output.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] Keyboard (component tests): arrows move between cells, Home/End jump to row edges, PageUp/PageDown move 12 rows, Enter edits an editable cell, Escape cancels
- [ ] Cells in rows whose editable flag is false cannot enter edit mode
- [ ] ARIA grid semantics asserted: role=grid/row/gridcell, aria-rowindex, a distinct role for subtotal rows
- [ ] Editable cells emit {rowKey, columnKey, value} with value as a decimal string, without mutating inputs
- [ ] 360 rows render within the test budget
