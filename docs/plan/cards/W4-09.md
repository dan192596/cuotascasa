## Entregables
provideSync() implementing SyncService: dynamic import of @cuotascasa/sync/google-drive on connect, DataStore adapted to LocalDataset, KeyStore wiring, passphrase setup (salt from the remote envelope if present, otherwise new), change passphrase, Spanish status signal, user-initiated sync(), disconnect() with revoke, 'no configurado' state when the build-time client ID is empty.

## Criterios de aceptación (objetivos, verificables por pruebas o CI)
- [ ] With the frozen fakes: connect -> setPassphrase -> sync uploads an envelope; a second device with the same passphrase merges; KeyMismatch asks for the passphrase
- [ ] Offline status reads 'cambios sin sincronizar (n)' with n = pendingChanges
- [ ] The Drive module loads only after connect() (import spy) and bundle:check stays green
- [ ] Storage inspection test: no token or passphrase persisted
- [ ] An empty client ID gives 'no configurado' and connect() disabled
- [ ] { state: 'error', code: 'InvalidRemote' } shows a Spanish message saying that the Drive copy cannot be read and that local data did not change (test)

## Notas
Launch context (D25): change the passphrase under SYNC_LOCK_NAME: decrypt the remote with the old key, re-encrypt with the new one, upload (keeping cuotascasa.prev.json), and only then KeyStore.save; otherwise the next sync on this device gets KeyMismatch.
